# ParishMart

Faith-driven commerce marketplace connecting parish stores, causes, local businesses and sponsors.

## Stack

- Next.js 16 (App Router, Turbopack)
- React 19
- TypeScript
- Tailwind CSS v4

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` Home — Shop with Purpose. Give with Love.
- `/shop`, `/shop/listing`, `/shop/product`, `/shop/cart`
- `/give`, `/give/cause`, `/give/checkout`
- `/stores` SKD parish storefront with sticky sub-nav
- `/local-businesses`, `/sponsors`
- `/search` Smart ecosystem search
- `/share-impact` Post-checkout sharing
- `/onboarding` for sellers, parishes, sponsors, local businesses
- `/dashboard` for each player type
- `/sign-in`

## Features

- Persistent cart with mini-cart drawer (localStorage)
- Impact breakdown showing where every dollar goes
- Trust badges (verified parish, approved seller, secure checkout)
- Mobile-first responsive layout with hamburger nav
- Sticky tab navigation on parish storefront
- Functional search with grouped results
- Stateful filters and amount pickers
